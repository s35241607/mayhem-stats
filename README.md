# ARAM: Mayhem 個人戰績小工具

在**你自己的電腦**上執行,直接讀取本機 League of Legends 客戶端的對戰紀錄,
統計「你自己」在 ARAM: Mayhem 模式裡,每個英雄玩了幾場、勝率多少。

## 為什麼要用這種方式

Riot 官方已經在 GitHub 上證實:ARAM: Mayhem(queueId 2400)的對戰資料被**刻意且永久性地封鎖公開 API 存取**,
所以任何第三方網站(op.gg、u.gg…)或工具都沒辦法查到「任何玩家」的個人 Mayhem 戰績 —— 包含你自己的帳號也一樣查不到。

官方原話是:「玩家只能在自己的客戶端裡面看到,除此之外沒有其他管道」。

這個工具走的正是「客戶端自己」用來顯示戰績頁面的那條路(本機 LCU API),不是被封鎖的公開開發者 API,
所以可以查到你自己的資料 —— 但也因為原理是「讀你自己客戶端的本機資料」,**無法查詢別人的帳號**(朋友、對手都不行),
這是 Riot 這邊的限制,不是這個工具做不到。

## 使用方式(uv)

需要先安裝 [uv](https://docs.astral.sh/uv/)(套件管理工具)。

1. 安裝套件、建立虛擬環境:
   ```bash
   uv sync
   ```
2. 打開 League of Legends 客戶端,登入到大廳畫面(不需要真的在遊玩中)。
3. 執行:
   ```bash
   uv run app.py
   ```
4. 瀏覽器開 <http://127.0.0.1:5057>,按「開始查詢」。

後端是 FastAPI + uvicorn,如果想自己控制啟動參數(例如換 port、開 `--reload`),也可以改成:
```bash
uv run uvicorn app:app --host 127.0.0.1 --port 5057
```

## 查詢範圍怎麼決定

工具會從最新的對局開始,一頁一頁往回掃(每頁 100 場),直到:

- 掃到帳號歷史的最底(該頁回傳空清單或不滿 100 場)—— 這時畫面會顯示「已經掃到最底」,代表這是這個帳號**目前能查到的完整** Mayhem 資料;
- 或掃了 6000 場還沒到底(安全上限,避免帳號歷史太長時卡住太久)—— 這時畫面會提示「可能還有更早的沒算進來」。

哪一種情況都會直接顯示出來,不用猜。順帶一提,Mayhem 這個模式是 25.21 版(2025/10/21)才上線的,
所以不管技術上限是多少,任何人的 Mayhem 紀錄本來就不可能早於這個時間點。

## 找不到客戶端 / 連線失敗怎麼辦

- 確認 League of Legends 客戶端**正在執行**(登入大廳就可以,不用進遊戲)。
- 工具會自動嘗試 Windows / Mac 常見的安裝路徑。如果你把客戶端裝在別的位置,
  在頁面最上面的輸入框手動貼上 lockfile 的完整路徑(這個檔案就在客戶端安裝資料夾裡,檔名就叫 `lockfile`)。
- 如果剛重開過客戶端,lockfile 內容會變,重新整理頁面再查一次即可。

## 隱私

所有運算都在你自己的電腦上完成,這個工具不會把任何資料送到任何伺服器
(除了讀取 Riot 公開的 Data Dragon 圖示/英雄名稱資料,那是公開靜態資源,不含你的個人資訊)。
